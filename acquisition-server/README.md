# 취득세 계산기 (서버 분리 버전)

계산 로직(세율 판정, 누진 공식, 부가세 규칙)이 서버에만 있어서
방문자가 페이지 소스나 개발자 도구를 봐도 계산 코드를 볼 수 없습니다.

## 폴더 구조

```
├── index.html          ← 화면(UI)만 담당. 방문자에게 보이는 파일
└── api/
    └── calculate.js    ← 모든 계산 로직. 서버에서만 실행되어 절대 노출되지 않음
```

## 동작 방식

1. 방문자가 금액을 입력하고 "계산하기"를 누르면
2. index.html이 입력값만 `/api/calculate`로 전송 (POST)
3. 서버가 계산해서 결과(세액, 계산 과정)만 돌려줌
4. 화면에 결과 표시

방문자가 볼 수 있는 것: 입력값과 결과뿐. 세율 판정 코드는 볼 수 없음.

## 배포 방법 (Vercel — 무료)

가장 간단한 방법입니다. 이 폴더 구조 그대로 올리면 됩니다.

### 방법 A: 웹에서 배포 (코딩 지식 불필요)

1. https://vercel.com 가입 (GitHub 계정으로 가능)
2. GitHub에 이 폴더를 저장소(repository)로 올림
3. Vercel에서 "Add New → Project" → 해당 저장소 선택 → Deploy
4. 끝. `https://프로젝트명.vercel.app` 주소가 생성됨

### 방법 B: 명령어로 배포

```bash
npm install -g vercel
cd 이_폴더
vercel          # 로그인 후 안내 따라 진행
vercel --prod   # 실제 배포
```

### 로컬에서 테스트

```bash
vercel dev
# http://localhost:3000 접속
```

주의: index.html 파일을 브라우저로 직접 열면 API가 없어서 계산이 안 됩니다.
반드시 `vercel dev` 또는 배포된 주소에서 확인하세요.

## 보안 관련 참고

- **API 주소가 코드에 보이는 것은 정상입니다.** 모든 웹사이트가 그렇게 동작합니다.
  중요한 건 API가 무엇을 하느냐인데, 이 API는 숫자를 받아 세액만 계산해
  돌려줄 뿐 비밀 데이터나 API 키가 전혀 없습니다.
- 서버에서 입력값 검증(숫자 여부, 상한선)을 이미 하고 있습니다.
- 트래픽 남용이 걱정되면 Vercel 대시보드에서 Firewall / Rate Limiting을
  켤 수 있습니다 (무료 플랜에서도 기본 DDoS 방어 제공).

## 참고: 화면에 표시되는 세율표

페이지 안내용으로 표시되는 세율표(1~3%, 중과 8%/12% 등)는 HTML 콘텐츠라서
여전히 보입니다. 이건 지방세법에 공개된 정보라 문제가 없지만,
이것마저 감추고 싶다면 index.html에서 해당 표 부분을 삭제하면 됩니다.
계산에는 전혀 영향이 없습니다 (계산은 전부 서버에서 하니까요).
